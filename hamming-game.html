Hamming formula, at a glance

2r ≥ k + r + 1

r is the number of parity bits and k is the number of data bits.

Parity bits go in positions 1, 2, 4, 8, … . The failed checks form a binary syndrome that identifies the faulty position.

How many bits were flipped?

Standard mode corrects one flipped bit. Extended Hamming (SECDED) adds an overall-parity bit to correct one error and detect, but not correct, two errors.

How to find the faulty bit

Each parity check returns either 0 (the checked bits have even parity) or 1 (odd parity, so the check fails). Put the results together to form the syndrome. The faulty bit can be a data bit or a parity bit; parity bits are included in their own checks, so the same method finds either kind.

  1. Number the received bits from left to right, starting at position 1.
  2. Check P1 at positions 1, 3, 5, 7; P2 at 2, 3, 6, 7; and P4 at 4, 5, 6, 7. Include the parity bit itself in each check.
  3. Write the results in P4 P2 P1 order. Convert that binary number to decimal; the result is the faulty position.
  4. Flip that position to correct the received codeword. This method assumes one flipped bit.

Data-bit example

Received codeword: 1010001

CheckBits checkedResult
P11, 3, 5, 7 → 1, 1, 0, 1Fails → 1
P22, 3, 6, 7 → 0, 1, 0, 1Passes → 0
P44, 5, 6, 7 → 0, 0, 0, 1Fails → 1

Syndrome P4 P2 P1 = 1 0 1₂ = 5. So bit 5 is faulty. Flip it to get 1010101.

Parity-bit example

Start with the same valid codeword 1010101, but this time parity bit 4 flips. The received codeword is 1011101.

CheckBits checkedResult
P11, 3, 5, 7 → 1, 1, 1, 1Passes → 0
P22, 3, 6, 7 → 0, 1, 0, 1Passes → 0
P44, 5, 6, 7 → 1, 1, 0, 1Fails → 1

Syndrome P4 P2 P1 = 1 0 0₂ = 4, so parity bit 4 is faulty. Flip it to recover 1010101. The game can choose any position for the single error, including parity positions.

Extended Hamming (SECDED)

Extended Hamming adds one overall even-parity bit after the regular Hamming code. The regular parity checks still form the syndrome; the overall check covers every bit, including the extra bit.

SyndromeOverall checkMeaning
0PassesNo error detected
Non-zeroFailsOne error in a regular Hamming position; correctable
0FailsError in the extra overall-parity bit; correctable
Non-zeroPassesTwo-bit error detected; the two positions cannot be identified from these checks

SECDED means single-error correction, double-error detection. It does not reliably correct two flipped bits.
